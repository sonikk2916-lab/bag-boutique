# Bag Boutique

Навчальний мінімагазин жіночих сумок. Авторки проєкту — Волощук Софія та Сажнєва Вікторія. Демонстраційна збірка використовує HTML, CSS та JavaScript без серверної частини і реальних платежів.

## Запуск

1. Розпакуйте архів і перейдіть у папку Bag_Boutique.
2. Відкрийте index.html у браузері. Для стабільної перевірки localStorage використайте локальний сервер.
3. Якщо встановлено Python 3, виконайте з цієї папки `python3 -m http.server 8000` і відкрийте http://localhost:8000.

## Функції

Каталог із шести карток, пошук за назвою та брендом, фільтри, сортування, обране, зміна кількості й видалення з кошика. Контактні поля демонстраційної форми перевіряються локально. Контакти не передаються та не зберігаються. Обране й кошик зберігаються в localStorage для поточного джерела сторінки, якщо браузер дозволяє збереження.

## Структура

- index.html і style.css — розмітка та оформлення.
- catalog.js — каталог і сталі ідентифікатори.
- logic.js — пошук, кількість, сума, перевірка форми, сховище.
- app.js — події інтерфейсу, рендеринг і синхронізація стану.
- images/ — шість фото, наданих для навчального проєкту.
- tests/shop.test.js — автоматизовані перевірки логіки.
- USER_MANUAL.md — посібник користувача.

## Тести

Установіть Node.js 18 або новішу версію та виконайте `node --test tests/shop.test.js`. Пакети npm для запуску сайту і тестів не потрібні.
